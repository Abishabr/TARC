# TARC-IMS

Tepi Agricultural Research Center Information Management System.

## Project structure

- `src/components` — shared UI primitives and layout.
- `src/features` — feature-based public and admin domain code.
- `src/lib` — low-level services, clients, and shared constants.
- `src/routes` — React Router configuration.
- `src/styles` — global styles and Tailwind entrypoints.

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env`
3. Run development server: `npm run dev`

## Recommended packages

React, React Router, React Query, Supabase, Tailwind CSS, React Hook Form, Zod, Framer Motion, Lucide React.
